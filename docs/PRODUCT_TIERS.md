## 1. 核心原则

| 原则 | 说明 |
|------|------|
| **两档制** | 仅「免费版」+「专业版」，**不做事务所版/企业版**（创始人确认） |
| **剪映式分层** | 免费版够用、专业版更爽、不卡核心流程（参考 action-tree §18） |
| **CPA 签发边界** | **报告必须由注册会计师签名才具法定效力**（《注册会计师法》第 25 条），软件只能输出「分析初稿」 |
| **数据主权** | 用户财务数据用户所有，软件只获租户内使用权，绝不跨租户售卖/训练公开模型 |

## 3. 详细功能矩阵

### 3.1 免费版（永久免费，获客主力）

**定位**：「单机版审计助手」—— 小微企业自查、会计学习、个人练手

| 模块 | 具体能力 | 限制 |
|------|----------|------|
| **凭证管理** | 手工新建、CSV 批量导入、凭证列表/筛选/编辑 | 单机本地存储，无云同步 |
| **OCR 识别** | 系统级 OCR (iOS Vision / Android ML Kit / HMS)、PaddleLite 端侧 | 单张识别，无批量队列，无服务端高精度 |
| **规则覆核** | 3 类基础规则 + 12 类扩展规则（内置种子规则） | 仅内置规则，无云端规则库更新 |
| **工作底稿** | 序时账、明细账、科目余额表、3+12 发现清单 | HTML 渲染，浏览器「另存为 PDF」 |
| **报告输出** | HTML 分析报告模板（基础版） | 无 PDF 专业模板、无 Word 模板 |
| **数据主权** | 完全本地，无上传 | 导出采集包可手动迁移 |
| **适用场景** | 个体户月度自查、会计专业学生练手、小微老板看账 | 非执业场景，不具备法定效力 |

### 3.2 专业版（订阅制，核心营收）

**定位**：「云端协作审计工作台」—— 执业会计师、代账会计、小微事务所

| 模块 | 具体能力 | 免费版差异 |
|------|----------|------------|
| **云端账套** | PostgreSQL 多租户隔离、自动备份、跨设备同步 | 免费版仅本地 SQLite |
| **服务端 OCR** | PaddleOCR 完整模型、批量队列、高分辨率、复杂版面、手写体增强 | 免费版仅端侧离线 |
| **团队复核** | 多角色（制单/复核/审核）、复核轨迹留痕、电子签名 | 免费版仅单人标记 |
| **专业模板库** | 政府红头审计报告、事务所底稿模版、跨境双语报告、银行授信报告 | 免费版仅 HTML 基础模板 |
| **AI 助手** | 基于用户历史风格起草报告正文、异常复述、风险提示语 | 月度 Token 配额（如 5 万 tokens/月） |
| **云端规则库** | 行业规则包（制造/贸易/建筑/服务业）、基准值自动更新、自定义规则 DSL | 免费版仅内置 12 条 |
| **多客户管理** | 客户档案、项目分组、权限隔离、批量切换 | 事务所/代账核心需求 |
| **批量操作** | 一键生成全套底稿包、批量导出 Excel/PDF、批量 OCR 队列 | 免费版逐个手动 |
| **API 接入** | REST API（凭证推送/发现拉取/报告生成） | 对接金蝶/用友/税务系统 |
| **数据保留** | 云端长期保留（订阅期内）+ 导出归档包 | 免费版仅本地文件 |

## 4. CPA 执业合规边界（红线）

> **法律依据**：《中华人民共和国注册会计师法》第 25 条、《中国注册会计师审计准则第 1301 号——审计报告》

### 4.1 软件能做什么（「分析初稿」）

- ✅ 凭证录入、分类、序时账自动生成
- ✅ 3+12 规则自动覆核，输出「风险发现清单」
- ✅ 基于模板生成「审计报告初稿/底稿草稿」
- ✅ 异常复述、数据可视化、交叉核对工作底稿
- ✅ 证据链自动串联（凭证→分录→发现→底稿→报告段落）

### 4.2 软件不能做什么（「法定效力」）

- ❌ **不能替代注册会计师签名**—— 报告法律效力仅来自 CPA 亲笔签名+盖章
- ❌ **不能承担审计意见责任**—— 软件不出具「无保留/保留/否定/无法表示意见」
- ❌ **不能替代职业判断**—— 重大错报风险评估、关键审计事项确定、重要性水平判断均需 CPA 决定
- ❌ **不能替代独立性程序**—— 利益冲突检查、独立性声明、质量控制复核均为人工

### 4.3 免责声明模板（内置于每份报告输出）

```
【重要免责声明】

本报告由「湛箴」审计智能体辅助生成，仅供注册会计师执业参考，构成「分析初稿」性质。

1. 本软件基于用户提供的凭证数据与规则引擎自动分析，不具备职业判断能力；
2. 所有风险发现、异常指标、报告措辞均为系统建议，最终结论必须由执业注册会计师复核确认；
3. 审计报告的法定效力仅来源于注册会计师亲笔签名、盖章及事务所盖章（依《注册会计师法》第 25 条）；
4. 用户应对输入数据的真实性、完整性负责；软件不对因数据错误导致的结论偏差承担责任；
5. 本软件不提供法律/税务/合规意见，相关判断请咨询执业专业人士。

—— 湛箴审计智能体 | 版本 v{version} | 生成时间 {timestamp}
```

> **落地要求**：每份导出报告（HTML/PDF/Word）必须在显著位置包含上述声明，不可移除。
