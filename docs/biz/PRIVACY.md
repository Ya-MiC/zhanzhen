## 1. 一句话结论

v0.1.0 本地模式下，你的全部业务数据**只存在你自己的机器上**；程序自身无遥测、无自动更新
回连；唯一的出网场景是你**主动配置** `ZZ_AI_*` 开启 AI 助手，且发送的是已确认的结构化字段
摘要——不是原始文件全文。

---

## 2. 数据存放位置（全部在本机）

以 `ZZ_DATA_DIR` 为根（路径选择见 [CONFIG.md](../user/CONFIG.md) §3.1）：

| 内容 | 位置 | 说明 |
|------|------|------|
| 原始凭证文件 | `$ZZ_DATA_DIR/objects-root/` | 按 SHA-256 寻址的对象存储，入库后只读 |
| 结构化账套 | `$ZZ_DATA_DIR/tenants/<ID>/snapshot-<ID>.json` | 凭证 VoucherJSON / 分录 / 发现 / 风格样本 / **完整事件链** |
| 导出物 | 你指定的输出目录 | `report.html`、序时账 `xlsx/csv` |
| 运行日志 | 进程 stdout | 不落凭证正文（错误信封不含堆栈） |

快照为**明文 JSON**：这是透明性优势（你随时能审计程序存了什么）也是保护要求
（目录权限收紧，见 [SECURITY.md](../dev/SECURITY.md) §6）。

### 2.1 快照里到底有什么（字段级透明）

`snapshot-<ID>.json` 顶层键与内容（来源 `store.py::save()`）：

| 键 | 内容 | 敏感度提示 |
|----|------|------------|
| `tenant_id` | 租户标识字符串 | 低 |
| `vouchers` | 每张凭证：状态 + 完整 VoucherJSON（类型/日期/三金额/单号/对手方名称税号/字段置信度）+ 关联分录号 | **高** |
| `entries` | 已确认分录行（科目/借贷金额/lines_hash/reversal 关联） | **高** |
| `findings` / `findings12` | 规则命中与处置记录 | 中 |
| `style_samples` | 你上传的历史报告文本头（前 2000 字符）、标题、字符数 | **高** |
| `exports` | 导出动作记录 | 低 |
| `events` | 全量事件链（含覆核修正的原值/新值对） | **高** |

## 3. 出网清单（穷举）

### 3.1 默认状态：零出网

不配置 `ZZ_AI_*` 时，程序没有任何主动网络请求。无埋点、无崩溃上报、无许可校验回连。

### 3.2 开启 AI 助手后：仅两类请求

目的地 = **你自己配置的** OpenAI 兼容端点（如 NVIDIA integrate / OpenRouter / 本地 vLLM）。
程序不内置任何硬编码服务商地址。

**① explain_findings（解释风险命中）发送的字段**
（来源 `ai_assistant.py::explain_findings` 的 context 构造，穷举）：

- `voucher_type`（凭证类型）、交易 `date`
- `amount_incl_tax / tax_amount / amount_excl_tax` 三个金额
- `document_no` 单号
- 对手方**名称**
- 命中规则的 `rule_id / severity / explanation` 摘要
- 原始文件 SHA-256 哈希值（仅为引用证据，不含文件内容）

**② suggest_accounts（科目候选）额外发送**

- 交易摘要 `summary`（OCR 提取时截取的正文首行前 60 字符——可能含品名等描述性文字）
- 同上的类型/金额/对手方/哈希

**永不发送**：原始 PDF/图片文件本体、事件日志全文、其他凭证的数据、你的文件系统任何
其他内容。API Key 仅用于对端点的 Authorization 头，不出现在留痕记录中。

### 3.3 第三方可见性提醒

启用云端 LLM 端点即意味着所选字段的摘要受该服务商隐私条款约束——这是你的配置决定。
敏感程度高的账套建议：不开启 AI，或使用自建/本地 vLLM 端点（`ZZ_AI_BASE_URL` 指向内网）。

## 4. `ZZ_AI_*` 边界细则

| 规则 | 事实依据 |
|------|----------|
| 默认关闭；三变量缺一即关闭，绝不静默联网 | `ai_assistant.py`：`enabled = bool(base_url and api_key and model)`，未启用抛 AIAssistantError |
| 只读已确认数据 | 助手只接收 store 里已确认的结构化字段与规则结论，没有任何写数据的 API |
| 输出不可信直入 | 响应强制过最小 schema 校验；失败即丢弃转人工，并留痕 schema_errors |
| 全程留痕 | 每次调用记录 prompt 版本 / 模型 / provider 主机名 / 响应哈希 / 校验结果（model_runs 单机等价物）。注：当前实现留痕在进程内存中，服务重启即清空，不落盘、不上传 |
| 不是零幻觉保证 | schema 校验拦截格式坏输出，但拦不住内容级错误——科目候选永远只是草稿参考 |

风格样本（`POST /v1/reports/upload-style-sample`）：存储截取的前 2000 字符文本头于本地
快照，代码注释明确「仅用于 AI 助手写作风格参考；原文存本地不外发」；不用于任何跨用户
或公开模型训练（权利条款见 ASSETS_AND_LICENSE.md §4）。

## 5. 数据生命周期一览

| 环节 | 本机模式行为 |
|------|--------------|
| 采集 | 手机拍照→采集包→工作台收包，传输限于你自己的网络路径（无厂商中转服务器） |
| 存储 | §2 所列目录；明文 JSON + 只读对象库；不加密静态存储（加密属专业版云端承诺） |
| 使用 | 仅为你驱动的工作流服务：OCR、规则、报告、（可选）AI 解释 |
| 共享 | 无共享；出网面仅 §3 穷举 |
| 备份 | 程序不做自动备份；由你复制目录实现（建议加密备份介质） |
| 删除 | §6 的整目录删除=彻底删除，无残留副本 |

## 5b. 承诺清单（红线）

1. 用户财务原始数据永远归用户所有；湛箴仅在提供服务必要范围内处理；
2. 绝不将 A 租户数据用于 B 租户训练、基准计算或任何形式共享；
3. 绝不用用户上传的历史报告训练公开模型；
4. 最小化收集：不收集设备指纹、位置、通讯录、浏览行为；
5. 无隐藏通道：出网面就是 §3 穷举的全部，多一行代码都会在开源仓库里可见。

## 5c. 常见误解澄清

- **「装了 `[ocr]` extra 是不是就把图片上传到 Paddle 云了？」**——不会。PaddleOCR 是本地
  推理库，模型下载后全程离线运行；且 v0.1.0 该 adapter 尚未提供（LIMITATIONS.md #1）。
- **「Vue 页面从 unpkg 加载 vue.js，我的数据会发过去吗？」**——页面脚本从 CDN 加载属于
  浏览器行为，业务请求全部发给本机后端；若要完全离线，可自行托管该文件或用 Docker 内网部署。
- **「trace_id 会暴露我的信息吗？」**——它只是随机短 ID，用于报障时定位日志，不含任何业务字段。

## 6. 删除方式

本地模式没有「云端副本」，删除是彻底删除：

```bash
# ① 停止服务（Ctrl-C 或 docker compose down）

# ② 删除数据根目录 —— 全部凭证/分录/事件链/风格样本随之消失
rm -rf "$ZZ_DATA_DIR"
# Docker 用户：宿主机挂载目录 rm -rf ./data

# ③ 导出物自行处置（报告/Excel 属于你，程序不会替你删）
# ④ 可选：pip uninstall zhanzhen && 删除虚拟环境
```

单项删除的现状（诚实声明）：

- 单张凭证删除端点 v0.1.0 未提供（状态机走向 ARCHIVED 而非物理删除，符合审计留痕惯例）；
- 需要物理清除特定凭证时：导出需保留的内容 → 整目录删除 → 新建空账套重录；
- style_samples 可在停机后直接编辑快照 JSON 移除（编辑后跑 `zhanzhen verify` 应仍为
  ✔——该数组不在事件链聚合内）。

订阅制云端版上线后的删除权（30 天彻底擦除含备份）承诺见 ASSETS_AND_LICENSE.md §4，
届时由正式 PRIVACY_POLICY.md 承接。

## 7. 多客户隔离实践（执业场景）

MVP 单租户下服务多客户的推荐姿势：**一家客户一个数据目录 + 一个租户 ID + 独立进程**：

```bash
ZZ_DATA_DIR=/srv/zz/client-a ZZ_TENANT_ID=client-a zhanzhen serve --port 8711
ZZ_DATA_DIR=/srv/zz/client-b ZZ_TENANT_ID=client-b zhanzhen serve --port 8712
```

目录互不可见即天然隔离；严禁把多家客户塞进同一实例再「指望程序分开」（SECURITY.md 缺口 #2）。
