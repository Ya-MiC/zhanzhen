# UI/UX 行业对标笔记（UI_AUDIT_NOTES）

> 读者：创始人、后续任何做界面的 AI/设计师。上游：ENGINEERING_SPEC §6、总纲 §7。

## 一、成熟审计/财务产品的界面模式（学什么）

| 模式 | 来源 | 湛箴落点 |
|---|---|---|
| 密集表格 + 行内快捷操作 | 金蝶/用友序时账、Excel 用户习惯 | 凭证箱默认表格，hover 才显示操作按钮 |
| 影像↔字段分屏对照 | 鼎信诺底稿工作台、Xero 收据核对 | 覆核页 grid2 分栏；v0.5 加影像预览列 |
| 风险热力配色 | MindBridge 高风险红/中琥珀/低灰 | finding 卡片左侧色条 + sev 徽章 |
| 结论可点击回源 | 四大电子底稿 cross-reference | 报告每条 finding 带证据哈希锚点 |
| KPI 大数卡 + 状态灯 | Stripe Dashboard / Vercel | 管理台仪表盘四卡 + 哈希链状态灯 |

## 二、湛箴 UI 三阶段演进

```
v0.3（当前）单页工作台：侧边栏导航 + 五页签，够小所日常用
v0.5       分栏专业操作台（spec §6.2 Windows 优先）：
           影像大图 + 快捷键流转(空格=通过/X=驳回) + 多凭证批量覆核队列
v1.0       多租户控制台：工作台按角色变体 + 管理台独立域名路径 + 白标
```

## 三、页面可用性验收清单（每次改 UI 必过）

- [ ] 覆核页：影像与字段并排；Tab 键顺序=字段顺序；Enter=保存
- [ ] 报告页：任一结论点击 ≤2 跳到达原始凭证 SHA-256
- [ ] 凭证箱：金额右对齐千分位；状态一眼可辨（色点+文案）
- [ ] 空状态：每个列表都有「没有数据时干什么」引导按钮
- [ ] 错误：永远 toast 中文可读话术，不弹原始堆栈
- [ ] 品牌：主蓝 #0F4C81 点缀金 #C9A063，不出现第三种主题色

## 四、给创始人提 UI 需求的沟通模板

> 「**哪个页面**（凭证箱/覆核/报告…）＋ **什么角色**（老板/会计/复核人）＋ **最高频的动作**是什么，
> 我希望点几次完成。」

例：「覆核页，会计，最常见动作是把 OCR 读错的日期改对并批准——希望不用鼠标纯键盘完成。」
收到这种描述即可直接改代码，不需要设计稿。
