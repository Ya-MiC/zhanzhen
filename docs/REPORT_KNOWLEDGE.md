# 报告知识库：写作手法与免费学习资源（docs/REPORT_KNOWLEDGE.md）

> 用途：AI 助手生成报告草稿时的「撰写思路库」；也是人类学习优秀审计报告写作的地图。
> 原则（总纲 §7）：高质量 ≠ 文字漂亮 = 结论可追溯 + 证据可解释 + 受准则约束。

## 一、报告按甲方分型的写法差异（写前必答三问）

写任何报告前先确认：**谁看？拿去干什么？依据什么标准？**

| 甲方场景 | 报告类型 | 结构重点 | 口径要点 |
|---|---|---|---|
| 银行/投标 | 财务报表分析+风险提示 | 指标表→趋势图→结论页 | 突出偿债/现金流；给「授信视角」结论 |
| 政府（补贴/高新认定） | 专项审计格式 | 政策条款对照表→逐项核验 | 引用文件号；口径与申报材料一致 |
| 企业老板 | 管理建议书 | 问题→影响→可执行建议 | 少术语多白话，每条建议配责任岗位 |
| 事务所内部 | 底稿+复核报告 | 程序执行记录→例外事项 | 每句可回溯到凭证号 |
| 跨境/外资 | 双语摘要 | CN/EN 对照+准则差异说明 | CAS vs IFRS 差异列明 |

**输出适配**：系统导出 PDF（打印版式）/ HTML（交互追溯）/ Markdown（再编辑）；
政府版式预留红头/落款位，企业版式预留 logo 位——由模板层处理（spec §9.2 版本化模板）。

## 二、优秀审计报告的写作手法（从公开范本提炼）

1. **金字塔结构**：结论先行 → 三层支撑（数据→异常→程序）→ 附录索引
2. **每段一个主张**：标题即结论（"应收账款周转天数恶化 23 天"而非"应收账款分析"）
3. **数字三件套**：绝对额 + 同比/环比 + 占比——只给一个数字的报告不可信
4. **例外导向**：正常的不写，偏离阈值的才进正文（Materiality 意识）
5. **风险语言分级**：「表明存在重大错报风险」>「需关注」>「建议留意」——措辞对应证据强度
6. **可追溯锚点**：每个结论带 [凭证SHA-256/底稿索引]（湛箴自动注入）
7. **建议 SMART 化**：谁、在什么期限、做什么、验收标准是什么

## 三、免费可学的公开审计报告资源

### 国际（英文，写作范式最规范）
- **SEC EDGAR** (sec.gov/cgi-bin/browse-edgar) — 全部美股 10-K 内含审计报告全文，PCAOB 准则范文；关键学 "Critical Audit Matters" 段落的论证结构
- **PCAOB** (pcaob.org) — 审计准则 AS 系列原文 + enforcement cases（反面教材）
- **IAASB** (iaasb.org) — ISA 国际准则；**ISA 701** 就是 CAM 写作方法论
- **英国 Companies House** (find-and-update.company-information.service.gov.uk) — 免费查英国公司年报，含 FRC 准则审计报告
- **四大年度透明度报告**（Deloitte/PwC/EY/KPMG 官网 Transparency Report 页）— 学质量控制语言
- **GRI/SASB** 样例 — 可持续报告的指标呈现手法

### 中国（中文，本地化口径）
- **巨潮资讯网** (cninfo.com.cn) — 全部 A 股上市公司年报审计报告免费全文；学「关键审计事项」中文表达
- **证监会/交易所问询函回复** — 反面问题清单：监管认为哪些披露不到位
- **中注协** (cicpa.org.cn) — 中国注册会计师审计准则原文（1601-1711 号等）
- **财政部会计司** — 企业会计准则应用指南（科目口径权威）
- **国家卫健委/教育部等部委** — 专项资金核查报告公示样本（政府口径）

### 学术/框架（免费 pip 包与工具）
| 包 | 用途 |
|---|---|
| `python-docx` / `docxtpl` | Word 版报告模板渲染（docxtpl 支持 Jinja 占位符）|
| `reportlab` / `weasyprint` | PDF 排版引擎（weasyprint 直接 HTML/CSS 转 PDF，推荐）|
| `jinja2` | 报告模板变量引擎（本仓 report.py 的升级路径）|
| `matplotlib` / `pyecharts` | 趋势图/结构图嵌入报告 |
| `openpyxl` | 底稿 Excel 自动生成（已内置）|
| `pandas` | 财务指标计算（比率/趋势/同比）|

## 四、账套模板参考（开源/公开格式）

> 只学**工作流与字段逻辑**，不复制专有模板内容（spec §9.2 边界）。

- **金蝶 KIS/K3 标准导出格式**：凭证明细 DLF/Excel 列结构（日期/凭证号/摘要/科目/借/贷）——湛箴 ingest 已兼容该列族
- **用友 T3/U8 账套接口**：ufinterface.xml 公开 schema——W4 连接器阶段对接
- **鼎信诺审计前端数据接口**：行业公认的数据采集格式（.mdb/.dbf 表族），字段映射见 docs/03 数据模型的 KingdeeUFida 映射表
- **财政部《企业会计准则》科目表 + 电子凭证会计数据标准**：科目编码唯一权威来源（本仓 mapping 即基于此）
- **GNUCash / Beancount**（MIT/BSD 开源记账）：复式簿记数据模型参考，beancount 的断言语法对「银行余额校验规则」设计有直接启发

## 五、湛箴报告生成管线（落地路径）

```
已确认账套 + findings(3+12) + style_samples(用户历史报告)
        ↓ jinja2 模板选择（按甲方类型）
报告骨架：封面→目录→结论摘要→分节发现→附录(证据索引)
        ↓ weasyprint → PDF / HTML 双输出
每条发现自动携带：rule_id + 金额 + evidence_refs + 建议程序
```

v0.5-beta 交付 docx/pdf 双模板；当前 v0.1 的 HTML 报告已是该结构的单页简化版。
